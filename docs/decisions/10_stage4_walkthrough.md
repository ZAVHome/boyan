# Отчет о реализации: Этап 4 — Web Desktop Frontend (SPA)

## 1. Краткое резюме выполненных работ

В рамках **Этапа 4** программного комплекса **Next-Gen OPDS Suite (Boyan)** разработан и верифицирован современный, высокопроизводительный, адаптивный десктопный SPA-клиент (`frontends/web-desktop`), реализованный на базе Vue 3 (Composition API, `<script setup lang="ts">`), Vite, Tailwind CSS, TypeScript, Pinia, Vue Router и расширяемой системы интернационализации `vue-i18n`:

1. **Дизайн-система и 4 обязательные темы оформления (`assets/styles/main.css`, `tailwind.config.cjs`):**
   - Реализована система дизайн-токенов на базе CSS-переменных:
     - `Light` (светлая чистая тема для дневного чтения).
     - `Dark` (современная контрастная темная тема).
     - `OLED Black` (чистый глубокий чёрный `#000000` для максимальной экономии энергии и контраста на OLED-экранах).
     - `Sepia` (тёплый пергаментный тон `#fbf0d9` для снижения усталости глаз).
   - Мгновенное бесшовное переключение тем через `ThemeToggle.vue` с сохранением выбора в `localStorage` и реактивной установкой атрибута `data-theme` на элементе `<html>`.

2. **Модульная расширяемая интернационализация (Extensible i18n, `src/i18n`):**
   - Реализована динамическая авторегистрация локалей через Vite `import.meta.glob('./locales/*.json', { eager: true })`.
   - Добавление любого нового языка (немецкий, французский, испанский и др.) выполняется простым добавлением одного файла `<lang>.json` в папку `locales/` с полем `"locale_name"` без необходимости правки исходного кода или компонентов!
   - Встроены полные локализации: Русский (`ru`) и Английский (`en`).

3. **Витрина каталога и детальная карточка книги (`CatalogView.vue`, `BookCard.vue`, `BookDetailModal.vue`):**
   - Отзывчивая сетка книг с обложками (с поддержкой ETag / 304 Not Modified), авторами, литературными циклами и форматами.
   - Переключение режимов отображения: «Сетка обложек» (Grid) и «Компактный список» (List).
   - Полнотекстовый поиск на лету с дебаунсом 300 мс.
   - Детальное модальное окно: вывод полной аннотации, ссылок на автора и серию, списка доступных файлов со ссылками скачивания и кнопки запуска веб-читалки.
   - Управление полками пользователя («Читаю сейчас», «Прочитано», «В избранное») с реактивным переключением.

4. **Универсальная встроенная веб-читалка (`BookReader.vue`, `reader.css`):**
   - Автоматический выбор и поддержка форматов: **FB2, FB2.ZIP и EPUB**.
   - Клиентская распаковка `.fb2.zip` на лету через `jszip` без сохранения временных файлов на диске.
   - Парсинг структуры глав, абзацев, встроенных base64-иллюстраций и сносок.
   - Интеграция `epubjs` для чтения книг в формате EPUB.
   - Интерактивное оглавление (TOC) с плавным переходом по главам.
   - Панель настроек типографики: выбор гарнитуры (Serif, Sans-serif, Monospace), размера шрифта (12px–36px), межстрочного интервала и ширины полосы чтения.
   - Автоматическая фиксация прочитанного процента с дебаунс-синхронизацией на сервер (`PUT /api/v1/books/{id}/progress`).

5. **Модерация очереди карантина (`QuarantineView.vue`, `QuarantineTable.vue`):**
   - Доступна администраторам (`role: admin`).
   - Наглядное сравнение конфликтующих файлов по SHA-256 хешу, названию, автору и формату.
   - Разрешение коллизий в один клик: «Заменить существующий файл», «Объединить форматы», «Оставить обе книги», «Отклонить и удалить».

6. **Пакетная и штучная загрузка книг (`UploadModal.vue`):**
   - Drag-and-drop зона с анимацией загрузки и индикацией статуса добавления книги.
