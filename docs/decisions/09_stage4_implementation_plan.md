# План реализации проекта Next-Gen OPDS Suite (Boyan) — Этап 4: Web Desktop Frontend (SPA)

## 1. Обзор задачи и цели этапа

Цель **Этапа 4** — создать современный, адаптивный, высокопроизводительный SPA-фронтенд для настольных компьютеров и планшетов (`frontends/web-desktop`), работающий по строгой Headless-архитектуре и взаимодействующий с бэкендом исключительно через REST API (`/api/v1/*`):

1. **Витрина каталога (Catalog Showcase):**
   - Отображение сетки книг с обложками (с поддержкой ETag / 304 Not Modified), авторами, сериями и форматами.
   - Переключение вида: «Сетка обложек» (Grid) и «Компактный список» (List).
   - Фильтрация по авторам (с алфавитным указателем), сериям, жанрам и новинкам.
   - Сортировка по названию, дате добавления, автору.
   - Полнотекстовый поиск на лету с дебаунсом.

2. **Карточка книги и управление:**
   - Детальный просмотр аннотации, издательских данных, ISBN, тегов жанров.
   - Скачивание файлов в доступных форматах (`fb2`, `fb2.zip`, `epub` и др.).
   - Управление полками пользователя («Читаю сейчас», «Прочитано», «Избранное»).
   - Отображение текущего прогресса чтения.

3. **Встроенная универсальная веб-читалка (Universal Web Reader):**
   - Полноценная поддержка форматов: **FB2, FB2.ZIP и EPUB** (на базе `epubjs` + нативный быстрый рендерер FB2/FB2.ZIP).
   - Оглавление и навигация по главам / TOC.
   - Настройка шрифта, размера текста, межстрочного интервала и ширины полосы чтения.
   - Автоматическая синхронизация прогресса чтения с сервером (`/api/v1/books/{id}/progress`) в процентах и позициях (CFI для EPUB, ID элементов/параграфов для FB2).

4. **Панель модерации дубликатов («Карантин»):**
   - Доступна администраторам (`role: admin`).
   - Наглядное сравнение конфликтующего файла с существующей книгой в библиотеке.
   - Действия: «Заменить существующий файл», «Объединить форматы», «Оставить обе книги», «Отклонить и удалить».

5. **Пакетная и штучная загрузка книг:**
   - Drag-and-drop зона для загрузки `.fb2`, `.fb2.zip`, `.epub` с индикацией статуса инжеста.

6. **Дизайн-система и 4 темы («День / Ночь»):**
   - Поддержка тем: `Light`, `Dark`, `OLED Black` (чистый #000000), `Sepia` (#f4ecd8 / #5c4033).
   - Дизайн-токены на CSS-переменных для мгновенного бесшовного переключения.

7. **Модульная система локализации (Extensible i18n):**
   - Архитектура с автоматической регистрацией и легким добавлением новых языков: достаточно положить `<lang>.json` в папку `locales/` и добавить в реестр языков.
   - Встроенные переводы: Русский (`ru`) и Английский (`en`), с возможностью добавления испанского, немецкого, французского и любых других языков за 1 минуту без правки компонентов интерфейса.

## 3. Детальный план реализации

### Шаг 1: Инициализация проекта Vite + Vue 3 + TypeScript
- Создание каркаса `frontends/web-desktop` с помощью `npm create vite@latest . -- --template vue-ts`.
- Установка зависимостей:
  - `vue-router@4`, `pinia@2`, `vue-i18n@9`
  - `tailwindcss`, `postcss`, `autoprefixer`
  - `lucide-vue-next` (иконки)
  - `jszip` (для прямой распаковки FB2.ZIP в веб-читалке)
- Настройка `vite.config.ts` с проксированием `/api` и `/opds` на `http://localhost:8080`.

### Шаг 2: Дизайн-система токенов и темы оформления
- Разработка `main.css` с переменными:
  - `--bg-primary`, `--bg-secondary`, `--bg-surface`, `--border-color`, `--text-primary`, `--text-secondary`, `--accent`, `--accent-hover`.
  - Четыре палитры: `light`, `dark`, `oled` (true black `#000000`), `sepia` (теплый пергаментный тон).
- Pinia Store `useThemeStore` с сохранением выбора в `localStorage` и реактивным обновлением атрибута `data-theme` на элементе `<html>`.

### Шаг 3: API Клиент и Pinia Stores
- `api/client.ts`: Fetch-обертка с поддержкой Bearer JWT, обработки 401 (автоматический редирект на логин) и отправкой cookies.
- `stores/auth.ts`: проверка текущего пользователя `/api/v1/auth/me`, методы `login`, `logout`, вычисляемые геттеры `isAdmin`, `isAuthenticated`.
- `stores/catalog.ts`: состояние загрузки, список книг, пагинация, текущие фильтры, история поисковых запросов.
- `stores/quarantine.ts`: список элементов на модерации, действия разрешения (`discard`, `replace`, `attach_format`, `keep_both`).

### Шаг 4: Компоненты навигации и витрины каталога
- `Navbar.vue`: адаптивный хедер со строкой мгновенного поиска, кнопкой загрузки книги, переключателем тем, селектором языка (RU/EN) и меню пользователя.
- `Sidebar.vue`: разделы «Все книги», «Авторы», «Серии», «Жанры», «Читаю сейчас», «Избранное», «Карантин (для админа)».
- `BookCard.vue`: элегантная обложка с ленивой загрузкой (`lazy`), бейджами форматов (`FB2`, `ZIP`, `EPUB`), индикатором серии и автора.
- `BookDetailModal.vue`: развернутая информация, модальное окно с описанием книги, ссылки на автора, список доступных файлов со ссылками скачивания и кнопкой «Читать онлайн».
- `UploadModal.vue`: зона сброса файлов для быстрой загрузки книг прямо в библиотеку.

### Шаг 5: Встроенная читалка FB2 в браузере (`BookReader.vue`)
- Загрузка контента через `/api/v1/books/{id}/download/fb2` (или распаковка `.fb2.zip` на лету через `jszip`).
- Парсинг XML-структуры (`<section>`, `<p>`, `<title>`, `<strong>`, `<emphasis>`).
- Вывод текста с поддержкой постраничного или непрерывного скролла.
- Настройки читалки: гарнитура (Serif / Sans-serif / Monospace), размер шрифта, межстрочный интервал, ширина колонки.
- Автоматическая фиксация прочитанного процента и отправка позиции через `PUT /api/v1/books/{id}/progress`.

### Шаг 6: Страница модерации дубликатов (`QuarantineView.vue`)
- Отображение очереди дубликатов в виде карточек сравнения:
  - Слева: загруженный файл (название, автор, размер, хеш, дата).
  - Справа: существующая книга в библиотеке (если найдена).
- Интерактивные кнопки разрешения коллизии:
  - «Заменить существующую версию»
  - «Прикрепить как новый формат»
  - «Сохранить как отдельную книгу»
  - «Отклонить и удалить»

### Шаг 7: Интернационализация (i18n)
- Файлы локализации `ru.json` и `en.json` с полным переводом интерфейса, названий разделов, кнопок действий и сообщений об ошибках.

## 4. План верификации

### Автоматизированные проверки
1. Сборка production-бандла: `npm run build` (проверка типов TypeScript и Vite).
2. Запуск линтера: `npm run lint`.

### Комплексное тестирование функционала
1. **Авторизация:** Вход под `admin` / `adminpassword`, проверка отображения профиля и сохранения токена в `localStorage`/cookie.
2. **Витрина каталога:** Отображение списка книг и обложек, фильтрация по жанрам и авторам, полнотекстовый поиск.
3. **Загрузка книг:** Загрузка `.fb2` через `UploadModal` и мгновенное появление книги в каталоге.
4. **Онлайн-читалка:** Открытие книги в ридере, изменение шрифта, тем оформления (OLED, Sepia), проверка сохранения прогресса чтения.
5. **Карантин:** Загрузка дубликата, появление в панели `/quarantine`, успешное разрешение конфликта.
6. **Темы:** Проверка бесшовного переключения 4 тем оформления (Light, Dark, OLED, Sepia) во всех окнах.
