# План реализации проекта Next-Gen OPDS Suite (Boyan) — Этап 5: Web Mobile PWA Frontend

## 1. Обзор задачи и цели этапа

Цель **Этапа 5** — создать Touch-first Progressive Web Application (PWA) для смартфонов, планшетов и специализированных ридеров на Android с экранами E-Ink (`frontends/web-mobile`):

1. **Touch-first эргономика для мобильных устройств:**
   - Нижняя навигационная панель (Bottom Navigation Bar) под большой палец: «Каталог», «Поиск», «Полки», «Офлайн-книги», «Настройки».
   - Управление жестами (Swipe navigation) в читалке: свайпы влево/вправо для листания страниц.
   - Зоны тапов для E-Ink: касание правой трети экрана — вперед, левой трети — назад, центр — вызов панели настроек.
   - Адаптивные мобильные карточки с мгновенным доступом к чтению.

2. **Офлайн-режим (Offline First & PWA):**
   - Интеграция `vite-plugin-pwa` с Service Worker, Web App Manifest и кешированием статических ассетов.
   - Локальное сохранение книг в `IndexedDB` (кнопка «Сохранить для офлайн-чтения»).
   - Раздел «Офлайн-библиотека»: чтение сохраненных книг без доступа к сети (в самолете, метро или на даче).
   - Фоновая синхронизация прогресса чтения при восстановлении подключения к сети.

3. **Специальный E-Ink режим (E-Ink High-Contrast):**
   - 100% монохромная высококонтрастная тема (абсолютный черный `#000000` текст на чистом белом `#ffffff` фоне, четкие 1px/2px границы).
   - Полное отключение CSS-анимаций и плавных переходов (`transitions: none`, `animation: none`) для исключения артефактов ("ghosting") и мерцания экрана электронных чернил.
   - Крупные элементы управления с контрастными пиктограммами.

4. **Универсальная мобильная читалка (FB2, FB2.ZIP, EPUB):**
   - Постраничный режим чтения (пагинация под размер экрана смартфона).
   - Быстрый парсинг FB2/ZIP и EPUB.
   - Настройка шрифта, размера и отступов.
   - Автосохранение позиции чтения локально и на сервере.

5. **Темы оформления и мультиязычность:**
   - 5 тем: `Light`, `Dark`, `OLED Black`, `Sepia` и `E-Ink Monochrome`.
   - Модульная расширяемая система `vue-i18n` (Русский и Английский из коробки + легкое добавление новых языков через JSON-файлы).

## 3. План верификации

### Автоматизированные проверки
1. Сборка production-бандла: `npm run build` (проверка типов TypeScript и Vite PWA).
2. Проверка генерации PWA манифеста и Service Worker (`sw.js`).

### Функциональные тесты в эмуляторе мобильных устройств
1. **Мобильный интерфейс:** Проверка BottomNav, открытия шторки деталей книги, поиска.
2. **Офлайн-режим:** Сохранение книги в IndexedDB, отключение сети (Network Offline) и успешное открытие книги в читалке.
3. **E-Ink Режим:** Переключение в монохромный режим, проверка отсутствия анимаций и 100% контрастности.
4. **Управление жестами:** Тапы по краям экрана и свайпы для перелистывания страниц.
