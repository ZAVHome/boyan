# Project Guidelines: Боян (Boyan)

## Project Overview
Боян (Boyan) — это модульный программный комплекс с открытым исходным кодом (Next-Gen OPDS Suite) для каталогизации, управления, веб-чтения и сетевой дистрибуции электронных книг (FB2, FB2.ZIP, EPUB, MOBI, PDF, DJVU) по протоколам OPDS v1.2 (XML/Atom) и OPDS v2.0 (JSON-LD).

## Architectural Principles (Strict Headless Architecture)
1. **Строгое разделение Backend и Frontend:**
   - Бэкенд написан на **Go (Golang)** и является полностью автономным (Headless). Он предоставляет исключительно REST API (OpenAPI 3.0 / Swagger) и эндпоинты OPDS v1.2 / v2.0.
   - Бэкенд НЕ содержит монолитных серверных HTML-шаблонов.
   - Фронтенды представляют собой независимые SPA/PWA приложения, взаимодействующие с бэкендом исключительно через документированный REST API.
2. **Поддерживаемые фронтенды:**
   - `web-desktop`: адаптивный SPA на Vue 3 + Tailwind CSS для ПК и планшетов (витрина, пакетное управление, онлайн-читалка, модерация дубликатов).
   - `web-mobile`: Touch-first PWA на Vue 3 + Tailwind CSS для смартфонов и Android E-Ink читалок (офлайн-режим, управление жестами, E-Ink контраст).
3. **Обязательные темы «День / Ночь»:**
   - Любой фронтенд обязан поддерживать темы: Light, Dark, OLED Black (чистый чёрный) и Sepia.
4. **База данных и поиск:**
   - База по умолчанию: **SQLite 3** в режиме `WAL` (Write-Ahead Logging) с внешними ключами.
   - Опционально: **PostgreSQL 15+**.
   - Полнотекстовый поиск: встроенный SQLite FTS5 со стеммингом для русского и английского языков.
5. **Совместимость с Calibre:**
   - Встроенный механизм чтения и импорта из существующих библиотек Calibre (`metadata.db`).
6. **Многоканальный инжест:**
   - Фоновый мониторинг папки с книгами через нативный `inotify` / `fsnotify`.
   - Автораспаковка FB2.ZIP на лету без предварительного сохранения временных файлов на диск.
   - Автономный **Telegram-бот** с поддержкой двусторонней работы (поиск/скачивание книг и входящая загрузка книг файлом прямо в чат).

## Tech Stack & Standards
- **Backend:** Go 1.23+, стандартная библиотека + `chi` (или `echo`), `sqlx` / `gorm` (или `ent`), `sqlite3` с FTS5.
- **Frontend:** Vue 3 (Composition API, `<script setup>`), TypeScript, Vite, Tailwind CSS, Pinia, Vue Router.
- **API Spec:** OpenAPI 3.0 (с автогенерацией Swagger UI на `/api/v1/docs`).
- **DevOps:** Docker Compose (мультиархитектурные образы amd64/arm64), Makefile, systemd-ready.

## Coding Conventions
### Go (Backend)
- Следуйте стандартным соглашениям `Effective Go` и `Go Code Review Comments`.
- Обрабатывайте все ошибки явно; не используйте `panic` в бизнес-логике.
- Логирование: структурированное логирование через `slog` (Go 1.21+).
- Все эндпоинты API должны быть задокументированы аннотациями `swag` / OpenAPI.
- При работе с файлами и архивами FB2.ZIP всегда используйте безопасные потоки и защиту от Zip Slip.
- Корректно обрабатывайте имена файлов с кодировками CP1251, CP866 и UTF-8, исключая возникновение surrogate escape символов.

### Vue 3 / TypeScript (Frontends)
- Используйте исключительно `<script setup lang="ts">` и Composition API.
- Для стилизации использовать утилитарные классы Tailwind CSS. Не писать кастомный CSS без крайней необходимости.
- Все цвета должны использовать CSS-переменные дизайн-токенов для бесшовного переключения тем (Light/Dark/OLED/Sepia).
- Текстовые строки интерфейса должны поддерживать интернационализацию через `vue-i18n` (русский и английский языки обязательно).

### Documentation & Decision Records (ADR)
- Все аналитические, сравнительные и проектные документы, подготовленные в ходе обсуждений и выбора архитектурных решений, обязательно сохранять в отдельную папку `docs/decisions/` с обновлением реестра `docs/decisions/README.md`.

## Development Commands
- `make run-backend`: запуск Go-сервера в режиме разработки
- `make run-desktop`: запуск десктопного фронтенда (Vite dev server)
- `make run-mobile`: запуск мобильного PWA фронтенда
- `make test`: запуск юнит- и интеграционных тестов
- `make docker-up`: запуск всех сервисов в Docker Compose
- `make swagger`: генерация документации OpenAPI / Swagger
