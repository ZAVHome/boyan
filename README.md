# Next-Gen OPDS Suite

> Модульный комплекс нового поколения для управления электронной библиотекой, чтения в браузере и сетевой дистрибуции по протоколам OPDS v1.2 и OPDS v2.0.

---

## 🌟 Ключевые возможности

- **Strict Headless Backend:** ядро на Go (Golang) с минимальным потреблением ресурсов (20–50 МБ RAM) и чистым OpenAPI 3.0 контрактом.
- **Поддержка FB2 / FB2.ZIP:** глубокий нативный парсинг вложенных архивов, многоуровневое дерево жанров с русским переводом, извлечение обложек на лету.
- **Двухстандартный OPDS:**
  - **v1.2 (Atom/XML):** 100% совместимость с AlReaderX, KOReader, PocketBook, Moon+ Reader.
  - **v2.0 (JSON-LD):** поддержка читалок нового поколения.
- **Два специализированных фронтенда (Vue 3 + Tailwind CSS):**
  - **Desktop:** современный медиа-хаб с витриной, онлайн-читалкой, пакетным редактором метаданных и модерацией дубликатов.
  - **Mobile PWA:** Touch-first управление свайпами, офлайн-режим и режим высокой контрастности для Android E-Ink экранов.
- **Обязательные темы «День / Ночь»:** Light, Dark, OLED Black и Sepia.
- **Telegram-бот двустороннего действия:**
  - Скачивание и инлайн-поиск книг прямо в мессенджере.
  - Добавление книг в библиотеку: просто отправьте файл `.fb2`, `.zip` или `.epub` в чат с ботом!
- **Автоматический инжест:** фоновый мониторинг папки с книгами через нативный `inotify` без нагрузки на диск.
- **Совместимость с Calibre:** возможность прямого импорта существующих библиотек из `metadata.db`.

## 📁 Структура репозитория

```text
├── backend/                  # Автономный Go бэкенд
│   ├── cmd/server/           # Точка входа в приложение (main.go)
│   ├── internal/
│   │   ├── api/              # HTTP роуты и контроллеры REST API
│   │   ├── opds/             # Генераторы фидов OPDS v1.2 и v2.0
│   │   ├── parsers/          # Парсеры FB2, EPUB, MOBI, PDF, архивов ZIP
│   │   ├── models/           # Модели данных (Book, Author, Series, Tag, User)
│   │   ├── storage/          # Слой работы с БД (SQLite WAL+FTS5 / Postgres)
│   │   ├── watcher/          # Демон автоимпорта и мониторинга inotify
│   │   └── enricher/         # Интеграции с FantLab, LiveLib, OpenLibrary
│   └── go.mod
│
├── frontends/                # Независимые фронтенды
│   ├── web-desktop/          # Desktop & Tablet Web SPA (Vue 3, Pinia, Tailwind)
│   └── web-mobile/           # Mobile Touch-First PWA (Vue 3, PWA, Offline mode)
│
├── services/
│   └── telegram-bot/         # Telegram бот (поиск, выдача и входящий инжест)
│
├── .agents/                  # Служебные правила и контекст для Antigravity IDE
│   └── rules/                # Архитектурные правила и спецификации
│
├── docs/                     # Документация и техническое задание (ТЗ)
├── docker-compose.yml        # Мультиконтейнерная оркестрация
├── config.example.yaml       # Пример файла конфигурации
├── Makefile                  # Команды автоматизации сборки и тестов
└── GEMINI.md                 # Конфигурация для Antigravity IDE
```

## 🚀 Быстрый старт

### Вариант 1: Запуск через Docker Compose (Рекомендуемый)

1. Скопируйте и настройте конфигурацию:
   ```bash
   cp config.example.yaml config.yaml
   ```
2. Запустите сервисы:
   ```bash
   docker compose up -d
   ```
3. Откройте в браузере:
   - Десктопный интерфейс: `http://localhost:3000`
   - Мобильный интерфейс: `http://localhost:3001`
   - OPDS v1.2 каталог: `http://localhost:8080/opds/v1/feed.xml`
   - Swagger API документация: `http://localhost:8080/api/v1/docs`

### Вариант 2: Локальная разработка

1. Запуск бэкенда:
   ```bash
   make run-backend
   ```
2. Запуск фронтенда (в отдельном терминале):
   ```bash
   make run-desktop
   ```
